# 戀愛沒那麼簡單

一款大約 15 分鐘的戀愛文字冒險。曖昧、熱戀、磨合、出軌、控制、分手，每個選擇都會留下痕跡，最後收進一本「結局之書」。

👉 立即遊玩：https://iammay22.github.io/situationship/

## 玩法

- 選擇自己的性別和名字，每一輪的對象、個性和劇情版本都不一樣
- 七種人格：溫柔體貼、慢熱寡言、熱情直球、忙碌上進、幽默搞笑、海王／海后、中央空調
- 四項數值：心動、信任、自我、友情。對方對你有多心動，你看不到
- 31 種結局，其中 5 個是隱藏結局
- 手機聊天、牽手、拍合照、深呼吸、整理相簿等小互動
- 隨機事件會避開這一輪看過的，也會優先抽你沒看過的
- 劇情裡穿插 37 張心理學小知識，收進「心理學圖鑑」，每張都附上研究出處

手機直向最好玩，平板和電腦也可以。

## 檔案

- `index.html`：整個遊戲，直接用瀏覽器打開就能玩
- `og-image.png`：分享連結時的預覽圖

遊戲進度和結局紀錄只存在你自己的瀏覽器裡。
